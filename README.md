# pcsx-redux/mips

Homebrew formulas for the `mipsel-none-elf` cross toolchain used to build PlayStation 1 software with [nugget](https://github.com/pcsx-redux/nugget) and [PCSX-Redux](https://github.com/grumpycoders/pcsx-redux).

```
brew install pcsx-redux/mips/mipsel-none-elf-gcc
```

This pulls in `mipsel-none-elf-binutils` as a dependency. A debugger is also available:

```
brew install pcsx-redux/mips/mipsel-none-elf-gdb
```

Everything is built from source, so installing gcc takes a while.
